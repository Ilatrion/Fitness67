# Fitness67 0.6 — как пользоваться

## 1. Установка
Скачайте Fitness67-v0.6.apk на Android и откройте файл. Разрешите установку из браузера/файлового менеджера, если Android спросит. Устанавливайте поверх предыдущего Fitness67, не удаляя приложение. Перед обновлением экспортируйте важный старый дневник. Новая версия сохраняет старое хранилище отдельно; часть прежних настроек и записи быстрых калорий без веса в новый интерфейс не переносятся.

## 2. Первый запуск и разрешения
Камера нужна для сканирования штрихкода. Физическая активность — для датчика шагов. Уведомления — для сообщений о пройденных шагах и работы фоновой службы. Разрешения запрашиваются при первом запуске Android, если доступны на этой версии ОС. Отказ не блокирует дневник; штрихкод можно ввести цифрами. Для повторной проверки откройте шестерёнку → Проверить разрешения / Открыть настройки телефона.

## 3. Ключ perek.us: простой вариант на телефоне
Откройте шестерёнку → Ключ perek.us. Вставьте свой ключ → Сохранить ключ. Один раз, без сервера. Это не ключ OpenAI. Он хранится зашифрованным и не входит в экспорт. Наличие ключа не означает, что доступ уже проверен: проверка выполняется первым онлайн-поиском. Если показано «Ключ или доступ отклонён», проверьте ключ и тариф в кабинете perek.us. При лимите дождитесь его восстановления. Не присылайте ключ в чат и не делитесь им.

## 4. Ключ из переменной PEREK_API_KEY: сборка на компьютере
Готовый контрольный APK собран без вашего ключа: значение ещё не предоставлено. Можно использовать пункт 3. Если хотите APK, в котором ключ уже задан, пересоберите исходники:

1. Распакуйте Fitness67-v0.6-AndroidStudio.zip.
2. В корне скопируйте .env.example в .env и запишите PEREK_API_KEY=ваш_ключ. Либо задайте переменную PEREK_API_KEY в окружении компьютера. Не публикуйте .env.
3. Откройте CMD в корневой папке проекта (где package.json) и выполните npm ci. Установите Node.js LTS, если npm отсутствует.
4. Выполните node scripts/catalog-key.mjs. Скрипт сообщит, что ключ задан, не показывая его.
5. В Android Studio откройте папку android. Нужны JDK 21, Android SDK 37 и Build Tools 37.0.0. Дождитесь Gradle Sync и запустите Gradle-задачу :app:assembleRelease. Можно из CMD: cd android, затем gradlew.bat assembleRelease.
6. APK появится в android/app/build/outputs/apk/release/app-release.apk. Установите его на телефон.

Переменная подставляется при сборке, телефон не читает переменные компьютера. Изменили ключ — пересоберите APK. Встроенный ключ извлекается из APK: такая сборка только для личного пользования. Кнопка «Отключить ключ» не стирает встроенный ключ из самого файла APK; отозвать его можно в кабинете perek.us. Для открытого веб-приложения нужен сервер: прямые браузерные запросы perek.us могут блокироваться CORS, а опубликованный бандл раскрывает ключ.

## 5. Сканирование
Сканер → Сканировать товар. Наведите на полоски EAN/UPC на упаковке (не на ценник и не на QR оплаты). Либо введите цифры в поле Штрихкод → Найти товар.

Сначала проверяется история и стартовый каталог на телефоне. Для поиска в интернете нажмите Проверить онлайн заново. perek.us проверяется при заданном ключе, Open Food Facts — без ключа. Состояние каждого источника видно отдельно. Встроено 278 стартовых карточек из USDA и Open Food Facts — это не полный каталог России или мира. Если товара нет, можно добавить его с упаковки. Фото бывает не у всех источников; заглушка не заменяется случайным изображением. Цифры — на 100 г либо на 100 мл, смотрите единицу.

## 6. Дневник и автоматизация
В карточке проверьте БЖУ и укажите порцию. Выберите завтрак, обед, ужин или перекус. Переключите Буду есть / Уже съел и нажмите Добавить в дневник. При повторном сканировании подставится последняя порция. В Дневнике запланированное можно отметить съеденным. Повтор вчерашнего приёма пищи копирует записи как план; повторное нажатие добавит ещё одну копию. Лишние записи можно удалить.

Мои товары содержит историю сканирований. Используйте поиск, избранное и повторное добавление без камеры. Рекомендации в карточке работают без нейросети: показывают частоту употребления за 7 дней и варианты из сохранённых товаров с большим количеством белка/углеводов либо меньшим количеством жира. Это сравнение на 100 г/мл, а не медицинский совет или доказательство дефицита.

## 7. Шаги и уведомления
Откройте Шаги. Задайте интервал, например 1000 → Включить шагомер. При первом запуске приложение может включить его после получения разрешения на активность, если есть датчик. Постоянное уведомление показывает работу счётчика, отдельные сообщения приходят при очередном рубеже. При нескольких рубежах в одной пачке датчика отправляется одно сообщение последнего рубежа.

Счёт идёт с включения, а не задним числом за весь день. Нужен аппаратный датчик TYPE_STEP_COUNTER. При его отсутствии приложение сообщит об этом. После перезагрузки откройте приложение и включите службу снова. Если уведомления не приходят, проверьте разрешение уведомлений, «Не беспокоить» и ограничения батареи. Остановить можно кнопкой в приложении или в постоянном уведомлении. Работа на физическом телефоне ещё требует проверки: сборка и автоматические тесты не заменяют реальную ходьбу с датчиком.

## 8. Темы
Шестерёнка → Оформление → Выбрать тему. Выберите Минимализм, Тёмный неон, Природа, Аниме, Ретро, iOS или Киберпанк. Тема сохраняется после закрытия приложения. Это оформление Fitness67, не изменение оболочки Android.

## 9. Резервная копия
Шестерёнка → Экспорт дневника JSON. Сохраните файл в свою папку или облако. Ключ perek.us в него не входит. Импорт этой новой копии в интерфейс версии 0.6 пока не реализован; экспорт нужен для сохранения и просмотра данных.

Скриншоты в PDF показывают веб-предпросмотр интерфейса. Они не демонстрируют реальные системные запросы Android или показания датчика. Успешный запрос с вашим настоящим ключом perek.us пока не выполнялся.
