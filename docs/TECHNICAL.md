# Ключ из переменной PEREK_API_KEY

Задайте PEREK_API_KEY в окружении компьютера или локальном .env (по .env.example). Запустите `node scripts/catalog-key.mjs` до сборки в Android Studio, либо `npm run apk` / `npm run build:web`. Скрипт генерирует локальный src/catalogBuild.ts, не печатая секрет. Этот файл исключён из git и исходного архива; после распаковки исходников сгенерируйте его заново. Если переменная не задана, создаётся пустое значение, доступен ввод ключа в Android.

Это подстановка при сборке, не чтение переменных компьютера с телефона. При замене переменной пересоберите APK/веб. Личный ключ, встроенный в APK/веб, можно извлечь; такую сборку не следует публично распространять. Веб-бандл с ключом нельзя публиковать в открытый доступ. Для публичного продукта нужен сервер. «Отключить ключ» отключает использование встроенного ключа в Android, но не удаляет его из APK; отзывайте ключ в кабинете поставщика. В текущей контрольной сборке ключ не задан: пользователь не предоставил защищённый доступ к PEREK_API_KEY.

# Fitness67 0.6 — сканер, дневник и шаги

Установите Fitness67-v0.6.apk поверх предыдущей версии. Идентификатор и подпись сохранены. Перед обновлением рекомендуем экспортировать старый дневник. Старые данные fitness67.v2 не удаляются. При первом запуске нового интерфейса записи с известным весом порции переносятся в новый дневник; записи быстрых калорий без массы остаются в старом хранилище и экспорте старой версии. Полного переноса настроек/целей старой версии нет.

## Главное
Четыре раздела: сканер, дневник, мои товары, шаги. OpenAI не используется. Нет оценки еды по фото. При первом запуске Android запрашивает камеру, физическую активность (Android 10+) и уведомления (Android 13+). Отказ не блокирует дневник и ручной ввод штрихкода. Разрешения можно проверить в настройках.

## Товары
В настройках введите личный ключ perek.us один раз. В Android APK он шифруется AES-GCM через Android Keystore в отдельном хранилище, исключённом из системного переноса/backup. Ключ не попадает в JSON дневника и исходники. Веб и Expo Go его не сохраняют. Это персональная Android-сборка с прямыми запросами: поставщик рекомендует сервер для публичного продукта. Не распространяйте ключ и не встраивайте общий ключ в публичный APK. Доступность и условия API зависят от поставщика. Настоящий ключ пользователя не получен; живой успешный запрос с ключом ещё не проверен.

Поиск сначала проверяет историю и 278 встроенных стартовых карточек (USDA FoodData Central CC0 и выборка российских карточек Open Food Facts ODbL/DbCL). Это не полный каталог. Онлайн запрашиваются perek.us (если ключ сохранён) и Open Food Facts параллельно. Источники и отказы показаны отдельно. USDA-онлайн в интерфейсе не включён: встроенные USDA-карточки доступны без ключа. FoodBase, FatSecret и Edamam в APK не подключены. Записи разных источников не смешиваются. Карточка на 100 мл сохраняет миллилитры, её не переименовывают в граммы. В perek.us фото может отсутствовать — показывается честная заглушка. Встроенные карточки и история доступны офлайн; внешние фото требуют интернета. Все четыре базовые величины должны быть известны, неизвестные не подменяются нулями.

Сканирование не означает автоматическую запись съеденного: пользователь проверяет порцию и подтверждает добавление. Последняя порция запоминается. Есть план/съедено, избранное и повтор вчерашнего приёма пищи. Собственные товары можно добавить с упаковки. История не является выгрузкой каталога поставщика.

## Подбор без нейросети
На карточке считается число съеденных записей того же штрихкода за последние семь календарных дней, без будущих дат и планов. При трёх и более отметках предлагается разнообразить выбор. Пользователь выбирает больше белка, больше углеводов или меньше жира; варианты из его товаров сравниваются на одинаковые 100 г / 100 мл. Это сравнение состава, а не медицинский вывод о дефиците. Клетчатка и другие неизвестные показатели не выдумываются.

## Шагомер
Нативный Android TYPE_STEP_COUNTER с foreground-службой типа health. Считает шаги с включения, не восстанавливает предшествующие шаги дня. На новом календарном дне обнуляется. Служба показывает постоянное уведомление с кнопкой остановки. Достижения — каждые выбранные 100–50 000 шагов (по умолчанию 1 000). При пакетной выдаче датчиком нескольких рубежей показывается одно уведомление последнего достигнутого рубежа. Доставка зависит от разрешения уведомлений, режима «Не беспокоить», датчика и ограничений батареи. После перезагрузки телефона откройте приложение и включите шагомер. Если датчика нет, подсчёт недоступен, случайные числа не показываются. В браузере и iOS нативного шагомера этой сборки нет.

## Темы
Настройки → Оформление → Выбрать тему: Минимализм, Тёмный неон, Природа, Аниме, Ретро, iOS, Киберпанк. Меняются палитра, формы и шрифты; расположение основных функций одинаковое. Тема сохраняется локально. Персонажи и внешние изображения для оформления не используются.

## Проверки
npm run typecheck
npm test
npm run build:web
python -m http.server 8094 --directory dist
npm run test:browser

Автотесты используют вымышленные ответы perek.us; успешный запрос с настоящим ключом не выполнялся. Android compile/signature проверяются отдельно. Скриншоты — веб-предпросмотр интерфейса, не доказательство работы датчика и системных разрешений. На физическом Android устройстве шагомер и уведомления пока не проверены.

## Android Studio
Откройте папку android, дождитесь Gradle Sync. JDK 21, SDK 37, target 36, min 24, Build Tools 37.0.0. Сборка: cd android, затем gradlew.bat assembleRelease на Windows или ./gradlew assembleRelease на Linux/macOS. Для сохранения совместимости обновления используется тот же учебный debug-keystore. Для публикации нужен собственный release-ключ. Поле perek.us добавлено в отдельную нативную сборку, в Expo Go недоступно.
